# AI search visibility scorecard

Use this scorecard to connect a priority search topic with an actual page, useful evidence, and a business decision. It is not a universal AI ranking score.

## Confirm the page foundation

- [ ] The canonical page returns a successful response.
- [ ] The page can be crawled and indexed.
- [ ] The main answer and supporting links are present in the rendered page.
- [ ] The page contains original experience, a useful example, or information that is not a generic summary.
- [ ] The author, organisation, and relevant service or project relationships are clear to a visitor.

## Record the outcome and next decision

- Qualified visits or enquiries attributed to the page:
- What changed since the previous review:
- What evidence suggests the change mattered:
- Next decision: improve content, add supporting evidence, remove a technical barrier, strengthen internal links, or leave the page unchanged.

Repeat the same fields weekly for a small set of priority pages. Compare meaningful changes over time, not isolated daily movements.
