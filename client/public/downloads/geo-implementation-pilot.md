AI impressions are already included in overall Web performance. Do not add them to Web totals. Ordinary query impressions and average position do not establish AI citations. The dedicated AI report does not provide query-level data. Query-filtered totals can exclude anonymised queries. Preserve unavailable statuses because AI report exports can represent unavailable values as zero.

## Technical checks

For each check, add pass / fail / not applicable, evidence, date and checker. Fix blockers before the content pilot and date repairs separately.

- [ ] Live page returns HTTP 200.
- [ ] Googlebot can access the page through robots.txt, hosting and CDN controls.
- [ ] Important answer text is present in Google's rendered view.
- [ ] No unintended noindex directive exists.
- [ ] Snippet controls permit the intended answer to be shown.
- [ ] URL Inspection index status is recorded.
- [ ] Declared and Google-selected canonicals are recorded; discrepancies are resolved or explained.
- [ ] Effective Search generative AI inclusion setting is recorded, including inherited control.
- [ ] Publisher's inclusion choice is respected; any proposed change is approved separately.
- [ ] Relevant internal links lead directly to the canonical page.
- [ ] Enquiry route works on mobile.
- [ ] Existing structured data matches visible content and is appropriate to the page.
