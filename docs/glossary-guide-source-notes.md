# Phase 2 glossary guide research sources

Research gathered 7 October 2026 for the Koupoli glossary guides.

- Google, [Overview of crawling and indexing topics](https://developers.google.com/search/docs/crawling-indexing): technical foundations include logical URL structure, sitemaps, robots directives, canonicalization, JavaScript handling, crawlable links, redirects, and monitoring site moves.
- Google, [Introduction to structured data markup in Google Search](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data): structured data should describe visible page content and should not be placed on blank pages created only to hold markup. Google recommends complete, accurate properties over excessive or poorly formed markup.
- Google, [Optimizing your website for generative AI features on Google Search](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide): Google describes generative features as rooted in its core Search index and quality systems. SEO fundamentals, crawlability, indexation, technical clarity, useful non-commodity content, and Search Console measurement remain central. Google says special AI-only markup, LLMS.txt files, mandatory chunking, and mass prompt-variation pages are not requirements for generative visibility.
- Google, [Generative AI performance reports](https://support.google.com/webmasters/answer/16984139): source for the use of Search Console data in AI-search visibility measurement.
- Google, [Creating helpful, reliable, people-first content](https://developers.google.com/search/docs/fundamentals/creating-helpful-content): source for the emphasis on original, useful, reader-first content.
- Google, [AI features and your website](https://developers.google.com/search/docs/appearance/ai-features): supporting guidance for AI-search visibility and eligibility.

The Phase 2 guides cite the relevant official Google source links in their on-page Sources sections.
